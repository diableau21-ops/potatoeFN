# PotatoFN

Site web de réglages Fortnite avec une interface gaming noire et violette.

## Lancer le site
Ouvre simplement `index.html` dans ton navigateur.

## Fonctionnalités
- Choix du mode graphique, de la résolution souhaitée et de la limite FPS.
- Téléchargement d'un aide-mémoire personnalisé au format TXT.
- Mise en page adaptée aux téléphones et aux ordinateurs.

## Important
Le site fonctionne dans le navigateur et ne modifie pas directement les fichiers de Fortnite ou les paramètres Windows. Les réglages doivent être appliqués manuellement dans le jeu.

Aucun outil de triche, macro ou modification du jeu n'est inclus.
